# Project memory

- Project: `create-my-pwa`, a dependency-light Node.js CLI generator.
- Entry point: `bin/cli.js` -> `src/cli.js`.
- V1 generates React + TypeScript + Vite + PWA scaffolding, optional Firebase Auth/Firestore/Storage/Functions/Hosting/Emulators, and optional Android TWA config.
- CLI supports `npm start -- <project-name>` and non-interactive defaults with `--yes`.
- Generated apps use `.env.example`; no project-specific Firebase values are hard-coded.
- README documents prerequisites, Firebase Console setup, config retrieval, `.env`, rules, emulators, deployment, and TWA setup.
- Auth generation also includes phone reCAPTCHA helpers, AuthProvider/useAuth, and ProtectedRoute.
- Generated apps now wrap the entry point with AuthProvider when authentication is enabled.
- ProtectedRoute uses an explicit ReactNode type import for strict TypeScript compatibility.
- Auth-enabled generated apps now route `/` and `/login` through React Router.
- Generated PWAs include real SVG app icons under `public/icons` for the manifest.
- CLI asks for npm, pnpm, or yarn and prints matching next-step commands.
- CLI supports `--help`/`-h` and `--version`/`-v`.
- Generated project README commands follow the selected package manager.
- Batch completion added auth login UI, Firebase metadata/messaging scaffold, PWA update component, and npm package metadata.
- Added generated `vite-env.d.ts`, realtime Firestore module, and root CLI tests.
- Package is intended for public npm distribution as `create-my-pwa`; README includes npx, global install, publishing, versioning, and package inspection steps.
- Generated app README now includes full prerequisites, Firebase setup/config retrieval, `.env`, rules, emulators, deployment, and Android TWA instructions.
- `src/cli.js` was formatted with Prettier; behavior preserved and checks/tests pass.
- Published `create-my-pwa@0.1.0`; current release is being prepared as `0.1.1`.
- Validation: run `npm.cmd run check`; generated apps need `npm install` before build validation.
- Keep this file updated when generator behavior or structure changes.
